# Referència de comandes

[English](commands_EN.md) · **Català**

kpapy afegeix aquestes comandes `spark` (grup `Kpapy` a `php spark list`). Els missatges són en anglès.

- [`kpapy:make`](#kpapymake): genera un recurs de l'API a partir d'una taula
- [`kpapy:openapi`](#kpapyopenapi): construeix el document OpenAPI
- [`kpapy:routes`](#kpapyroutes): llista els recursos de l'API i els permisos per què pregunten
- [`kpapy:token`](#kpapytoken): crea un token d'accés per a un usuari
- [`kpapy:publish`](#kpapypublish): copia la configuració o un fitxer d'idioma al projecte
- [`kpapy:demo`](#kpapydemo): instal·la, reinicia o treu la demo

Relacionada: `php spark migrate -n Kpapy` crea la taula de l'inici de sessió de les apps (`kpapy_login_challenges`).

---

## kpapy:make

Genera el mètode de controlador i les rutes d'un recurs de l'API a partir d'una taula: les relacions surten de les claus foranes (amb la primera columna de text de la taula relacionada), els filtres de les claus foranes, enums, booleans i dates, i la cerca de les columnes de text.

```bash
php spark kpapy:make <taula> [opcions]
```

| Opció | Descripció |
|---|---|
| `--namespace` | Espai de noms base de l'aplicació o del mòdul (per defecte `App`) |
| `--path` | Directori de l'espai de noms (per defecte, el de l'autoloader) |
| `--routes` | Fitxer de rutes (per defecte `<path>/Config/Routes.php`, es crea si no existeix) |
| `--controller` | Controlador, relatiu a `<ns>\Controllers` (per defecte `Api/<Taula>`) |
| `--method` | Mètode (per defecte `index`) |
| `--route` | Camí de la ruta (per defecte `api/v1/<taula>`) |
| `--resource` | Nom del recurs per als permisos (per defecte, la taula) |
| `--as` | Nom de la ruta |
| `--filter` | Filtre de la ruta (per defecte `kpapy`) |
| `--extends` | Classe pare d'un controlador nou (per defecte `<ns>\Controllers\BaseController`, `App\Controllers\BaseController` o `CodeIgniter\Controller`) |
| `--dry-run` | Mostra el codi sense escriure res |
| `--force` | Substitueix el mètode si ja existeix |

El controlador es crea si no existeix; si no, s'hi afegeix el mètode (o se substitueix amb `--force`) i es completen les línies `use`. La ruta no s'afegeix dues vegades.

```
$ php spark kpapy:make kpapy_demo_books --dry-run

--- App\Controllers\Api\KpapyDemoBooks ---
    /**
     * API resource for the "kpapy_demo_books" table (generated by "php spark kpapy:make").
     */
    public function index(): ResponseInterface
    {
        return (new Resource())
            ->setTable('kpapy_demo_books')
            ->setResource('kpapy_demo_books')
            ->setRelation('author_id', 'kpapy_demo_authors', ['name'])
            ->filters(['author_id', 'available'])
            ->searchFields(['title', 'isbn', 'audience', 'cover'])
            ->render();
    }

--- /home/user/kpapy/demo/app/Config/Routes.php ---
\Kpapy\Resource::routes($routes, 'api/v1/kpapy-demo-books', 'Api\\KpapyDemoBooks::index', ['filter' => 'kpapy']);
```

En un mòdul (el controlador s'escriu amb el nom complet de la classe, i es crea el `Config/Routes.php` del mòdul si cal; CodeIgniter el carrega amb el descobriment de rutes):

```bash
php spark kpapy:make posts --namespace "Modules\Blog" --route api/v1/posts --resource blog-posts --as api-posts
```

Després adapta el codi generat (camps, camps d'escriptura, regles…) i declara els permisos del recurs.

## kpapy:openapi

Construeix el document OpenAPI 3.1 de les rutes registrades amb `Resource::routes()` i `AuthRoutes::register()`.

```bash
php spark kpapy:openapi [--output fitxer] [--format json|yaml] [--prefix api/v1]
```

| Opció | Descripció |
|---|---|
| `--output` | Fitxer on s'escriu (relatiu al projecte). Sense, el document es mostra per pantalla |
| `--format` | `json` (per defecte) o `yaml` |
| `--prefix` | Només les rutes que comencen per aquest camí |

```
$ php spark kpapy:openapi --prefix kpapy-demo/api/v1 --output public/openapi.json
Written public/openapi.json (21 paths).
```

Un recurs que no es pot descriure (p. ex. un controlador que necessita un paràmetre al constructor) es mostra com un avís i s'omet.

## kpapy:routes

Llista els recursos de l'API, si necessiten token, el nom del recurs i tots els permisos per què pot preguntar (`permissionCatalogue()`): la llista que cal declarar al teu sistema de permisos.

```
$ php spark kpapy:routes
+--------------------------------+--------+-----------------+-----------------------------------------------------------------------------------+
| Path                           | Auth   | Resource        | Permissions asked                                                                 |
+--------------------------------+--------+-----------------+-----------------------------------------------------------------------------------+
| kpapy-demo/api/v1/books        | token  | library-books   | list, show, add, edit, delete, search, filters, bulk, trash, restore, purge, lend |
| kpapy-demo/api/v1/authors      | token  | library-authors | list, show, add, edit, delete, search, filters, bulk                              |
| kpapy-demo/api/v1/tags         | token  | library-tags    | list, show, add, edit, delete, search, filters, bulk                              |
| kpapy-demo/api/v1/my/loans     | token  | library-loans   | list, show, search, filters, bulk, return                                         |
| kpapy-demo/api/v1/public/books | public | library-public  | list, show, search, filters                                                       |
+--------------------------------+--------+-----------------+-----------------------------------------------------------------------------------+
```

## kpapy:token

Crea un token d'accés de Shield per a un usuari, p. ex. per a una integració entre servidors (necessita `codeigniter4/shield`).

```bash
php spark kpapy:token <email|id> [--name Console] [--scopes a,b] [--days N]
```

| Opció | Descripció |
|---|---|
| `--name` | Nom del token (per defecte `Console`) |
| `--scopes` | Abasts separats per comes: `recurs.operació`, `recurs.*` o `*` (per defecte `*`) |
| `--days` | Dies fins que caduca (`0` = mai; per defecte `tokenLifetime`) |

```
$ php spark kpapy:token reader@kpapy.demo --name ERP --scopes library-books.list,library-books.show --days 90
Token for reader@kpapy.demo (copy it now, it will not be shown again):
52c598121c62b5f4209cfbb5128ba59fdf1cf832f35f6396c62a0da21d72f852
Scopes:  library-books.list, library-books.show
Expires: 2027-02-01T13:37:31+01:00
```

## kpapy:publish

Copia la configuració o un fitxer d'idioma al projecte per adaptar-los.

```bash
php spark kpapy:publish config [--force]          # app/Config/Kpapy.php amb totes les opcions i comentaris
php spark kpapy:publish lang <ca|es|en|fr|pt|de>  # app/Language/<locale>/Kpapy.php
```

Treu dels fitxers publicats el que no canviïs: les opcions i textos que esborris prenen el valor de la llibreria.

## kpapy:demo

Instal·la, reinicia o treu la demo (vegeu [demo/README_CA.md](../demo/README_CA.md)).

```bash
php spark kpapy:demo install [--force] [--allow-production]
php spark kpapy:demo status
php spark kpapy:demo reset [--yes]
php spark kpapy:demo uninstall [--yes]
```

| Opció | Descripció |
|---|---|
| `--force` | `install`: primer treu una instal·lació anterior |
| `--yes` | `reset`, `uninstall`: no demana confirmació |
| `--allow-production` | `install`, `reset`: s'executa encara que `ENVIRONMENT` sigui `production` (qualsevol podria obtenir un token de la demo: evita-ho) |

La demo necessita Shield instal·lat i migrat, i la migració de kpapy (`php spark migrate --all`).


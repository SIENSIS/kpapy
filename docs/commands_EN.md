# Command reference

**English** · [Català](commands_CA.md)

kpapy adds these `spark` commands (group `Kpapy` in `php spark list`). Messages are in English.

- [`kpapy:make`](#kpapymake): generate an API resource from a table
- [`kpapy:openapi`](#kpapyopenapi): build the OpenAPI document
- [`kpapy:routes`](#kpapyroutes): list the API resources and the permissions they ask for
- [`kpapy:token`](#kpapytoken): create an access token for a user
- [`kpapy:publish`](#kpapypublish): copy the configuration or a language file into the project
- [`kpapy:demo`](#kpapydemo): install, reset or remove the demo

Related: `php spark migrate -n Kpapy` creates the table of the app login (`kpapy_login_challenges`).

---

## kpapy:make

Generates the controller method and the routes of an API resource from a database table: the relations are taken from the foreign keys (with the first text column of the related table), the filters from the foreign keys, enums, booleans and dates, and the search from the text columns.

```bash
php spark kpapy:make <table> [options]
```

| Option | Description |
|---|---|
| `--namespace` | Base namespace of the app or module (default `App`) |
| `--path` | Directory of the namespace (default: from the autoloader) |
| `--routes` | Routes file (default `<path>/Config/Routes.php`, created if missing) |
| `--controller` | Controller, relative to `<ns>\Controllers` (default `Api/<Table>`) |
| `--method` | Method (default `index`) |
| `--route` | Route path (default `api/v1/<table>`) |
| `--resource` | Resource name for the permissions (default: the table) |
| `--as` | Route name |
| `--filter` | Route filter (default `kpapy`) |
| `--extends` | Parent class of a new controller (default `<ns>\Controllers\BaseController`, `App\Controllers\BaseController` or `CodeIgniter\Controller`) |
| `--dry-run` | Show the code without writing anything |
| `--force` | Replace the method if it already exists |

The controller is created if it does not exist; otherwise the method is added (or replaced with `--force`) and the `use` lines are completed. The route is not added twice.

```
$ php spark kpapy:make kpapy_demo_books --dry-run

--- App\Controllers\Api\KpapyDemoBooks ---
    /**
     * API resource for the "kpapy_demo_books" table (generated by "php spark kpapy:make").
     */
    public function index(): ResponseInterface
    {
        return (new Resource())
            ->setTable('kpapy_demo_books')
            ->setResource('kpapy_demo_books')
            ->setRelation('author_id', 'kpapy_demo_authors', ['name'])
            ->filters(['author_id', 'available'])
            ->searchFields(['title', 'isbn', 'audience', 'cover'])
            ->render();
    }

--- /home/user/kpapy/demo/app/Config/Routes.php ---
\Kpapy\Resource::routes($routes, 'api/v1/kpapy-demo-books', 'Api\\KpapyDemoBooks::index', ['filter' => 'kpapy']);
```

In a module (the handler is written with the full class name, and the module's `Config/Routes.php` is created if needed; CodeIgniter loads it with route discovery):

```bash
php spark kpapy:make posts --namespace "Modules\Blog" --route api/v1/posts --resource blog-posts --as api-posts
```

Then adapt the generated code (fields, write fields, rules…) and declare the resource's permissions.

## kpapy:openapi

Builds the OpenAPI 3.1 document of the routes registered with `Resource::routes()` and `AuthRoutes::register()`.

```bash
php spark kpapy:openapi [--output file] [--format json|yaml] [--prefix api/v1]
```

| Option | Description |
|---|---|
| `--output` | File to write (relative to the project). Without it, the document is printed |
| `--format` | `json` (default) or `yaml` |
| `--prefix` | Only routes starting with this path |

```
$ php spark kpapy:openapi --prefix kpapy-demo/api/v1 --output public/openapi.json
Written public/openapi.json (21 paths).
```

A resource that cannot be described (e.g. a controller that needs a constructor argument) is reported as a warning and skipped.

## kpapy:routes

Lists the API resources, whether they need a token, their resource name and every permission they can ask about (`permissionCatalogue()`): the list to declare in your permission system.

```
$ php spark kpapy:routes
+--------------------------------+--------+-----------------+-----------------------------------------------------------------------------------+
| Path                           | Auth   | Resource        | Permissions asked                                                                 |
+--------------------------------+--------+-----------------+-----------------------------------------------------------------------------------+
| kpapy-demo/api/v1/books        | token  | library-books   | list, show, add, edit, delete, search, filters, bulk, trash, restore, purge, lend |
| kpapy-demo/api/v1/authors      | token  | library-authors | list, show, add, edit, delete, search, filters, bulk                              |
| kpapy-demo/api/v1/tags         | token  | library-tags    | list, show, add, edit, delete, search, filters, bulk                              |
| kpapy-demo/api/v1/my/loans     | token  | library-loans   | list, show, search, filters, bulk, return                                         |
| kpapy-demo/api/v1/public/books | public | library-public  | list, show, search, filters                                                       |
+--------------------------------+--------+-----------------+-----------------------------------------------------------------------------------+
```

## kpapy:token

Creates a Shield access token for a user, e.g. for a server-to-server integration (requires `codeigniter4/shield`).

```bash
php spark kpapy:token <email|id> [--name Console] [--scopes a,b] [--days N]
```

| Option | Description |
|---|---|
| `--name` | Name of the token (default `Console`) |
| `--scopes` | Comma-separated scopes: `resource.operation`, `resource.*` or `*` (default `*`) |
| `--days` | Days until it expires (`0` = never; default `tokenLifetime`) |

```
$ php spark kpapy:token reader@kpapy.demo --name ERP --scopes library-books.list,library-books.show --days 90
Token for reader@kpapy.demo (copy it now, it will not be shown again):
52c598121c62b5f4209cfbb5128ba59fdf1cf832f35f6396c62a0da21d72f852
Scopes:  library-books.list, library-books.show
Expires: 2027-02-01T13:37:31+01:00
```

## kpapy:publish

Copies the configuration or a language file into the project to customise them.

```bash
php spark kpapy:publish config [--force]          # app/Config/Kpapy.php with every option and comment
php spark kpapy:publish lang <ca|es|en|fr|pt|de>  # app/Language/<locale>/Kpapy.php
```

Delete from the published files what you do not change: the options and texts you remove take the library's value.

## kpapy:demo

Installs, resets or removes the demo (see [demo/README_EN.md](../demo/README_EN.md)).

```bash
php spark kpapy:demo install [--force] [--allow-production]
php spark kpapy:demo status
php spark kpapy:demo reset [--yes]
php spark kpapy:demo uninstall [--yes]
```

| Option | Description |
|---|---|
| `--force` | `install`: remove a previous installation first |
| `--yes` | `reset`, `uninstall`: do not ask for confirmation |
| `--allow-production` | `install`, `reset`: run even if `ENVIRONMENT` is `production` (anyone could get a demo token: avoid it) |

The demo needs Shield installed and migrated, and the kpapy migration (`php spark migrate --all`).

```
$ php spark kpapy:demo install

```

